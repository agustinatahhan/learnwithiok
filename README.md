# Learn with IOK - Educational Landing Page

A professional, high-conversion landing page designed for an English language educator. The project focuses on seamless user experience (UX) and streamlined student onboarding.

## 🚀 Key Features
- **Integrated Scheduling:** Full Calendly integration for real-time lesson booking and automated scheduling.
- **Service Optimization:** Detailed sections for methodologies, pricing, and bio, optimized for readability.
- **Performance-First:** Built with static site generation (SSG) to ensure near-instant loading times and high Core Web Vitals scores.

## 🛠️ Tech Stack
- **Frontend:** Next.js (App Router), TypeScript.
- **Styling:** Tailwind CSS (Mobile-first, responsive design).
- **Tools:** Calendly API / Widget integration.

## 🧠 Technical Challenge
The main goal was to integrate a third-party booking system that felt native to the UI while maintaining the site's performance and SEO rankings.
